# Forge Portfolio — Preliminary U.S. Trademark Shortlist

Updated: 2026-10-03

This is a **preliminary naming/filing triage**, not a legal clearance opinion. Before spending filing fees, each finalist should receive a comprehensive clearance search for confusingly similar marks and related goods/services. USPTO specifically recommends searching federal records plus state registrations, the internet, and other common-law sources.

Official starting points:

- USPTO trademark search: https://www.uspto.gov/trademarks/search
- Federal searching guidance: https://www.uspto.gov/trademarks/search/federal-trademark-searching
- Likelihood of confusion: https://www.uspto.gov/trademarks/search/likelihood-confusion
- Current fee information: https://www.uspto.gov/trademarks/trademark-fee-information

The current USPTO base application fee is **$350 per class**, with possible additional fees depending on the application.

## Priority A — worth a formal clearance search before filing

### WildTake Studio

**Preliminary position:** strongest current portfolio candidate for a paid clearance pass.

A quick public-web check did not surface the same level of obvious software/product collision seen with several other portfolio names. That is **not** proof the mark is clear. Search spelling variants, WILD TAKE, WILDTAKE, related entertainment/media software, creator tools, video-production services, and relevant classes before filing.

### AJ Job Fisher

**Preliminary position:** worth a formal clearance pass if this is intended to become a real public product.

The full composite name is more specific than generic “job finder” language, but parts of the name are suggestive/descriptive. The commercial value of federal registration should be weighed against how central this product will be to the portfolio.

## Priority B — keep using as project names, but do not pay to file yet

### HealthQA Auditor

Useful descriptive portfolio name, but its wording directly describes a health/QA auditing function. Distinctiveness may be weaker than a more coined brand.

### CareFlow Research Lab

Useful project identity, but CAREFLOW-style wording is common in healthcare/workflow contexts. It needs a deeper clearance pass and may not justify early filing spend.

### RaterLab

Short and memorable, but “rater” + “lab” is suggestive of an evaluation/calibration tool and the name is already used in other research contexts. Hold until the product has a clearer commercial path.

## Hold / rename before spending filing money

### Forge AI / Forge

**High concern.** A live 2026 U.S. application exists for **FORGE AI** covering AI/software-related services. The wider software market also contains numerous Forge-branded developer and AI products. Do not treat “Forge AI” alone as a clean flagship mark.

### MedForge

**High concern.** MedForge is already used commercially in healthcare software/services, including MedForge Orchestrator and MedForge Insight. A separate 2026 research project also uses MEDFORGE. Do not spend on a filing under the current name without specialist clearance and likely rebranding analysis.

### VocalForge

**High concern.** Multiple existing software projects already use VocalForge for vocal/audio tooling, including a desktop vocal-recording/mixing application that is especially close to our product concept. Rename before commercialization or filing.

### SearchSignal

**High concern.** SearchSignal is already used by a current SEO workspace/API product. That is very close to our SEO/GEO software field. Rename before commercialization or filing.

### StudyForge

**High concern.** Multiple active education/study products use StudyForge, including AI study applications and an established education platform. Do not file the current name without a major clearance review; a rename is the cleaner path.

### CiteGuard

**High concern.** CiteGuard is already used by multiple citation-verification products/projects, including active research/software tools and commercial-facing citation products. Rename before commercialization or filing.

### PairRank

**High concern.** PairRank is an established name in pairwise learning-to-rank research and is also used by a current ranking web product. Rename before commercialization or filing.

### Elias

**High concern as a standalone software mark.** ELIAS already appears in live/registered U.S. marks involving downloadable software/SaaS. If Elias remains the assistant character/product identity, use a more distinctive composite brand and run a proper clearance search before filing.

### GrimForge / GrimForge Cinema

**Meaningful concern.** GrimForge is already in public use for game/character-creation projects, including a current Warhammer-related character creator and another game project. “GrimForge Cinema” is more specific, but the shared dominant term still needs a formal confusion analysis before any filing.

### ServiceBridge Advocate

**Meaningful concern.** SERVICEBRIDGE is already an established field-service software platform and is also used by an AI/digital-engineering business. Adding “Advocate” does not automatically eliminate confusion risk. Do not make this the first paid filing without specialist clearance.

### Benchmark Forge

**Meaningful concern.** “Benchmark Forge” is already being used for AI-evaluation/benchmark tooling and FORGE is crowded in AI/software. Keep as a project label unless renamed to something more distinctive.

### Forge Learn / Forge Builder

**High concern.** The FORGE software/developer ecosystem is crowded, and “Forge Learn” / “Forge Builder” are highly suggestive combinations. These are better treated as internal suite descriptors unless the umbrella branding is changed and cleared.

## Recommended filing order

Do **not** batch-file the current portfolio names.

1. Run a comprehensive clearance search on **WildTake Studio**.
2. Run the same search on **AJ Job Fisher** only if it is becoming a public/commercial product.
3. Decide on a more distinctive **umbrella replacement for Forge AI** before paying to register the suite.
4. Rename the clearest collision risks first: **VocalForge, SearchSignal, StudyForge, CiteGuard, MedForge, PairRank**.
5. After the umbrella and flagship names are stable, identify the actual goods/services and classes, filing basis, owner, and specimens before submitting anything.

## Filing rule

Use **™** only as an unregistered brand indicator where appropriate. Do not use **®** unless and until the USPTO registers that specific mark for the relevant goods/services.
